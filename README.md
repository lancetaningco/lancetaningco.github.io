# lancetaningco.github.io

Personal portfolio site for Lance Taningco — electrical engineering student at Cal Poly Pomona. Built with plain HTML/CSS/JS and hosted on GitHub Pages.

- `index.html` — Home, About, and Contact sections
- `projects.html` — full project list
- `script.js` — theme toggle + `PROJECTS` array (edit this array to add/update projects)
- `styles.css` — site styling
